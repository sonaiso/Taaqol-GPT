# 119 — General Algebra Observatory Foundation Law (GUA-OBS-L0)

> Status: law-only constitutional foundation (no runtime, no datasets, no curriculum execution).
> Scope: open the observatory governance layer after `GUA-1R.2` chain reconciliation.
> Snapshot date: 2026-08-22.

## §1 Constitutional role

`GUA-OBS-L0` separates two historical phases:

1. guarding licensed transition integrity (`GUA-1R` family), and
2. experimentally discovering what remains invariant across licensed transitions.

This law opens only the second phase at constitutional level.

## §2 Governing law

```text
No GeneralInvariant from GeneralHypothesis alone.
No GeneralInvariant from one-domain success.
No learning claim from correct answer alone.
No cross-domain necessity claim from cross-domain correlation alone.
No observatory promotion with hidden residuals.
Every promoted invariant remains demotable under valid counter-evidence.
```

## §3 Licensed observatory chain

`GUA-OBS-L0` licenses the following candidate-first chain:

```text
GeneralHypothesis
-> DomainProjection
-> DomainEvidence
-> LearningEvidence
-> CrossDomainInvariantCandidate
-> GeneralInvariant
```

Direct shortcut is forbidden:

```text
GeneralHypothesis -/-> GeneralInvariant
```

## §4 General hypothesis boundary

`GeneralHypothesis` is not `GeneralLaw`.

A hypothesis is only admissible if it carries:

```text
Claim, Scope, Variables, Falsifiers, ExpectedInvariant, Rank, Residuals
```

No hypothesis is constitutional without explicit falsifier conditions.

## §5 Domain projection and domain evidence

`DomainProjection` is mandatory between hypothesis and evidence.
The observatory must not force one domain's implementation language onto another.

`DomainEvidence` is admissible only with explicit:

```text
Objects, Units, Operations, EvidenceType,
PositiveCases, NegativeCases, BoundaryCases, Counterexamples, Residuals
```

`DomainEvidence` may promote to `DomainInvariant`, never directly to `GeneralInvariant`.

## §6 Learning evidence boundary

Domain validity is not equivalent to learner capability acquisition.
Learning evidence must satisfy all of:

```text
P (Positive) AND
N (Negative) AND
A (Adversarial) AND
T (Transfer) AND
B (Boundary awareness)
```

No learning closure is licensed if boundary awareness is absent.

## §7 Cross-domain invariant discipline

Cross-domain comparison operates on transition geometry, not raw scores.
Invariant admission is licensed only as:

```text
InvariantUnderControlledVariation
```

Controlled variation must include explicit perturbation of domain, carrier, task,
evidence type, learner, representation, and case distribution.

## §8 Rank, promotion, and demotion

Observatory ranking is staged from hypothesis to stronger candidate states.
Any promotion requires visible residuals and trace continuity.
Demotion is mandatory when valid counter-evidence appears.

No observatory outcome is a final metaphysical certainty claim.

## §9 Forbidden shortcuts

The following shortcuts are constitutionally forbidden:

```text
FoundationalText -/-> GeneralLaw
GeneralHypothesis -/-> CrossDomainInvariant
DomainSuccess -/-> GeneralLaw
CorrectAnswer -/-> Learning
RepeatedExampleSuccess -/-> Capability
SharedTerm -/-> SharedConcept
SharedConcept -/-> SharedLaw
CrossDomainCorrelation -/-> CrossDomainNecessity
LearningEvidence -/-> TruthOfDomainLaw
```

## §10 Boundary of this step

`GUA-OBS-L0` does not:

- add runtime carriers, evaluators, or gates,
- register datasets,
- open curriculum execution paths,
- mutate `src/taaqqul_slot_geometry/gua/` runtime semantics.

Operational epistemic-record semantics and non-skipping measurement-chain
discipline are defined by `docs/120_GENERAL_ALGEBRA_OBSERVATORY_EPISTEMIC_RECORD_LAW.md`.

## §11 Security and trust-model note

Module-private names (leading underscore) are API-discipline boundaries, not
cryptographic secrecy primitives against adversarial code in the same process.
Constitutional claims must not overstate this boundary.
