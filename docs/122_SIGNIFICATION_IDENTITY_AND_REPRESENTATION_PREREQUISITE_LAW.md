# 122 — Signification Identity and Representation Prerequisite Law (GUA-OBS-SIG0)

> Status: law-only constitutional boundary (no runtime, no carriers, no ORM implementation, no datasets).
> Scope: define semantic-identity admissibility prerequisites between `GUA-OBS-ES0` and `OBS-H0`.
> Snapshot date: 2026-08-22.

## §1 Constitutional role

`GUA-OBS-SIG0` binds observatory entry to semantic identity discipline before
hypothesis registration.

Governing thesis:

```text
No evidence evaluation without semantic identity.
No admissible hypothesis without licensed semantic identity references.
```

## §2 Placement and dependency

`GUA-OBS-SIG0` is licensed only after:

- `docs/119_GENERAL_ALGEBRA_OBSERVATORY_FOUNDATION_LAW.md` (`GUA-OBS-L0`)
- `docs/120_EPISTEMIC_SELF_STATE_DERIVATION_LAW.md` (`GUA-OBS-ES0`)

and must precede:

- `OBS-H0` (general hypothesis registry law),
- `OBS-D0` (domain projection/evidence contracts),
- `OBS-LE0` (learning event/evidence contracts),
- `OBS-X0` (cross-domain comparison),
- `OBS-P0` (promotion/demotion governance),
- any `OBS-ORM-*` runtime realization.

## §3 Semantic identity chain

Before `GeneralHypothesis` admission, semantic identity must be licensed as a
bounded chain:

```text
DistinguishableUnit
-> CarrierIdentity
-> SignifierIdentity
-> SignifiedIdentity
-> SignificationContract
-> DomainTerm
-> DefinitionBoundary
-> LexicalUsageWitness
-> GlossaryAdmission
-> SemanticIdentityRef
```

No shortcut is licensed from raw string, bare term, or free concept claim to
`SemanticIdentityRef`.

## §4 Mandatory separations

`GUA-OBS-SIG0` binds the following non-equivalences:

```text
Carrier =/= Signifier
SignifierIdentity =/= SignifiedIdentity
Signification =/= Truth
Definition =/= Evidence
TermIdentity =/= ClaimValidity
LexicalLicense =/= RealityCorrespondence
```

and preserves observatory separation:

```text
SharedTerm -/-> SharedConcept
SharedConcept -/-> SharedLaw
```

## §5 Minimum complete signification datum

Semantic-identity admission requires `MCSD`:

```text
MCSD = <
  Unit,
  Carrier,
  Signifier,
  Signified,
  Binding,
  Domain,
  Scope,
  Definition,
  Residuals,
  Trace
>
```

`MCSD` licenses question-formation readiness only. It is not evidence of claim
truth and not a promotion signal.

## §6 Semantic drift and comparability

Cross-experiment or cross-domain comparison is unlicensed when semantic drift
is not tracked:

```text
NoExperimentalComparisonUnderUntrackedSemanticDrift
```

Any concept-identity change that affects comparison must be recorded as a
traceable event with residual visibility.

## §7 Evidence relation boundary

No admissible `Evidence(e,p)` posture without identity binding for:

```text
SemanticIdentity(e)
AND SemanticIdentity(p)
AND RelationIdentity(EvidenceRelation)
AND DomainBinding
```

`LicensingWitness` for semantic identity is distinct from `ClaimEvidence`.

## §8 Hypothesis admission implication

`OBS-H0` admission must require semantic readiness as a prerequisite:

```text
SemanticIdentityRefSet -> HypothesisAdmissionGate -> AdmittedGeneralHypothesis
```

If semantic closure for testing is not met, the legal posture is refusal/
deferral class (for example `SEMANTICALLY_UNDERDETERMINED` or
`NOT_ADMISSIBLE_FOR_TESTING`), not claim falsity.

## §9 Forbidden shortcuts

```text
String -/-> Meaning
SignifierIdentity -/-> SignifiedIdentity
TermIdentity -/-> EvidenceAuthority
LexicalOccurrence -/-> ClaimEvidence
Definition -/-> ClaimTruth
RepresentationChange -/-> ConceptChange
UntrackedSemanticShift -/-> ExperimentalComparability
```

## §10 Boundary of this step

`GUA-OBS-SIG0` does not:

- add runtime code under `src/`,
- add observatory carriers/contracts implementations,
- add persistence models, ORM schemas, migrations, or adapters,
- add lexicon ingestion pipelines or external dictionaries,
- open domain evidence, learning evidence, or invariant promotion execution.
