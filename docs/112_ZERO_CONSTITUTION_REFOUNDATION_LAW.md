# 112 — Zero Constitution Refoundation Law (Z0)

> Status: constitutional refoundation boundary document (law-only).
> Scope: define the Z0 constitutional reference chain and the legal remapping discipline for legacy artifacts.
> Snapshot date: 2026-08-19.

## §1 Constitutional role

`Z0` is a refoundation law, not a runtime-opening law.

It does not invalidate prior ratified laws. It reclassifies their constitutional position under a stricter chain geometry.

This step opens no runtime code, no commit authority, no canonical mutation, no certificate issuance, and no truth/reality closure.

```text
Every legacy proof remains valid inside its originating law boundary,
```

## §5 Legacy compatibility matrix covenant

Every pre-Z0 artifact that remains in scope must be explicitly mapped to exactly one state:

- `KEEP`
- `RETYPE`
- `REORDER`
- `QUARANTINE`
- `REBUILD`

Mandatory rule:

```text
One artifact -> one primary remap state at a time.
No silent dual status.
```

Interpretation:

- `KEEP`: remains valid and positionally compatible in Z0 with no semantic widening.
- `RETYPE`: same boundary intent preserved, but contract/type surface must be rewritten.
- `REORDER`: artifact validity preserved but chain position must change.
- `QUARANTINE`: legacy path preserved for backward trace only; not a licensed Z0 forward path.
- `REBUILD`: existing artifact is insufficient for Z0 obligations and requires a new bounded successor.
