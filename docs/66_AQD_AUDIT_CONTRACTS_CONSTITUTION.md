## §1 Governing decision

The uploaded AQD language idea is constitutionally usable only as a
proof-bearing contract source. It is not accepted as a runtime language.

```text
AQD as runtime language        ✗
AQD as audit contract surface  ✓
```

The code licensed by this document may define frozen dataclasses, local
constants, schema guards, proof-reference requirements, forbidden output
surfaces, residual labels, and tests. It may not evaluate language,
execute examples, emit operational products, open relation runtime, open
semantic runtime, or authorize any binding kernel.

## §4 Proof-reference discipline

AQD contracts do not inspect proof truth. They require references to
proof objects or proof traces:

```text
proof_object_ref | proof_trace_ref
```

A missing proof reference is a malformed AQD contract. A present proof
reference is not authority; it is only an auditable locator for a later
licensed proof layer.

Boolean proof shortcuts are forbidden. Evidence names, relation labels,
surface tools, and temporal references do not become proof by being
present in an AQD contract.

---

## §5 Relation discipline

AQD relation fields are relation-function candidates. A surface tool or
letter may never produce a final relation by itself.

```text
surface tool -> RelationFunctionCandidate needing bridge proof  ✓
surface tool -> final relation runtime                          ✗
```

The relation triplet records previous, next, and next-to-previous
relation references, but relation authorization remains false and
relation runtime remains closed.

---

## §6 Inflection and time discipline

AQD may carry temporal references:

```text
temporal_scope_ref
utterance_time_ref
attribute_time_ref
temporal_policy_ref
```

Those references do not execute time. They do not define all iʿrāb.
Inflection remains an audit shape for a licensed relation effect on a
carrier; no final iʿrāb, final meaning, ifādah, hukm, tanzīl, or reality
is produced.

## §7 Morphological branch discipline

AQD may describe a morphological branch contract, but a surface weight
does not open derivation by itself:

```text
SurfaceWeight(x) -> DerivationLicense(x)  ✗
```

The contract may reference path cards, masdar opening, denominal branch
licensing, and residual policy. It may not execute derivation.
